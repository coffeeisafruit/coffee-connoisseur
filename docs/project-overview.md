# Coffee Connoisseur — Project Overview

> Generated by BMad `document-project` (Deep Scan) on 2026-06-14. Primary AI-context entry point: [index.md](./index.md).

## Purpose

Coffee Connoisseur is a full-stack web application for coffee enthusiasts to
**discover, track, and perfect their brewing**. Tagline (from the landing page):
*"For the Connoisseur, Not the Snob."*

## Tech Stack (summary)

| Layer | Technology |
|-------|-----------|
| Frontend | React 19, Vite 7, TypeScript 5.9, Tailwind CSS 4, Radix UI / shadcn (new-york), wouter (routing), TanStack Query 5, framer-motion |
| API transport | tRPC 11 (`@trpc/server`, `@trpc/react-query`) over HTTP batch link, superjson transformer |
| Backend | Express 4, Node (ESM), tsx (dev), esbuild (prod bundle) |
| Database | MySQL via Drizzle ORM 0.44 + `mysql2`; migrations by drizzle-kit |
| Auth | Manus-platform OAuth (`server/_core/sdk.ts`) + JWT session cookie (`jose`) |
| External services (via Manus "Forge" proxy) | Object storage (photo upload), Google Maps, OpenAI-compatible LLM, voice transcription, image generation |
| Validation | zod 4 (input schemas on every tRPC procedure) |

## Repository Classification

- **Type:** Multi-part monorepo (single repo, two deployable concerns sharing one build)
- **Parts:** `client` (web frontend) · `server` (backend API) · with `shared/` (cross-cutting types/consts) and `drizzle/` (schema + migrations)
- **Package manager:** pnpm 10
- **Platform origin:** Scaffolded on the **Manus WebDev** platform (`vite-plugin-manus-runtime`, Forge API proxy for storage/maps/LLM). This is significant: storage, maps, and LLM credentials are injected by the platform via `BUILT_IN_FORGE_API_URL` / `BUILT_IN_FORGE_API_KEY`, not configured directly.
