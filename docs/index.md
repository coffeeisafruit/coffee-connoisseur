## Project Overview

- **Type:** Multi-part monorepo (2 parts) — `client` (web) + `server` (backend), with `shared/` + `drizzle/`
- **Primary Language:** TypeScript (ESM)
- **Architecture:** React 19 SPA ⇄ tRPC ⇄ Express ⇄ Drizzle/MySQL; single-origin serving
- **Platform origin:** Manus WebDev (Forge proxy for storage/maps/LLM)

## Quick Reference

### client (web frontend)
- **Tech:** React 19, Vite 7, Tailwind 4, tRPC react-query, TanStack Query, wouter, Radix/shadcn
- **Entry:** `client/src/main.tsx` → `client/src/App.tsx`
- **Routes:** `/`, `/quiz`, `/profile`, `/journal`, `/roasters`

### server (backend API)
- **Tech:** Express 4, tRPC 11, Drizzle ORM, mysql2, zod, jose, openai
- **Entry:** `server/_core/index.ts`
- **API:** `/api/trpc/*` (tRPC) + `/api/oauth/callback`

## Getting Started (for development)
